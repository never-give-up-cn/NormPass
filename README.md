# NormPass — 中文密码测试网站

> **一套完整的中文密码处理工程方案：Unicode NFC 标准化 + UTF-8 存储 + bcrypt/Argon2 哈希 + 登录编码兼容**

## 项目背景

绝大多数网站对中文密码的支持存在缺陷：编码不一致、Unicode 等价字符问题、旧客户端编码错乱等。  
NormPass 提供了一套 **可验证的中文密码完整解决方案**，并在测试网站中完整实现。

## 核心流程

```
注册：明文 → NFC 标准化 → UTF-8 编码字节 → bcrypt 哈希 → 入库
登录：明文 → NFC 标准化 → 用户选择编码字节 → 比对 UTF-8 哈希
```

### 设计要点

| 原则 | 说明 |
|------|------|
| **存储唯一标准** | 所有密码哈希基于 NFC + UTF-8 字节生成，数据库仅存一条哈希 |
| **编码兼容** | 登录时可选 GBK/GB2312/UTF-16LE，仅用于修复老旧客户端编码错乱 |
| **白名单校验** | 后端硬编码允许集合 `{utf-8, gbk, gb2312, utf-16le}`，其余一律拒绝 |
| **NFC 归一化** | 解决组合字符（如 `é` vs `e + ◌́`）视觉相同但码点不同的问题 |
| **strict 编码** | 字符无法用选中编码表达时直接抛异常，绝不使用 `�` 占位符 |

## 快速启动

### 1. 环境要求

- Python 3.10+
- MySQL 5.7+

### 2. 安装依赖

```bash
pip install flask flask-login bcrypt pymysql cryptography
```

### 3. 初始化数据库

```bash
mysql -u root -p < schema.sql
```

### 4. 修改数据库配置

编辑 `config.py`，确认数据库连接信息：

```python
DB_CONFIG = {
    "host": "localhost",
    "user": "root",
    "password": "YOUR_PASSWORD",
    "database": "passtest",
}
```

### 5. 启动服务

```bash
python app.py
```

访问 **http://127.0.0.1:5000/** 即可使用。

## 页面功能

### 注册页 `/register`
- 支持中文、Emoji、生僻字作为密码
- 无编码选择，强制 UTF-8 标准存储

### 登录页 `/login`
- 编码选择下拉框（默认 UTF-8）
- 三种错误反馈：
  - **1001** — 密码错误
  - **2001** — 所选编码不支持输入字符（生僻字/Emoji），建议切换 UTF-8
  - **4000** — 非法编码参数

### 首页 `/`
- 登录后展示测试场景参考

## API 协议

### 错误码

| 码值 | 含义 | 用户提示 |
|------|------|---------|
| 0 | 登录成功 | 跳转首页 |
| 1001 | 密码错误 | "密码输入错误" |
| 2001 | 编码不兼容 | "所选编码不支持输入文字，请切换 UTF-8" |
| 4000 | 非法编码 | "不支持的编码格式" |

### 限流规则

同一账号连续 5 次登录失败 → 临时锁定 10 分钟。

## 运行测试

```bash
python test_e2e.py
```

覆盖 6 项测试：NFC 标准化、bcrypt 哈希、UTF-8 登录、编码兼容（含 Emoji/GBK 边界）、非法编码拦截、账号锁定。
